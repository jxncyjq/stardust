# 国际化参考

## 适用场景

当你需要在 stardust 中接入 go-i18n、本地化消息或请求语言解析时，先看这里。

## 组件和中间件

- `components.I18nComponent()` 负责读取 `i18n` 配置并加载嵌入式翻译文件。
- `middleware.I18n()` 负责解析 `?lang=` 和 `Accept-Language`，并把 `Localizer` 挂到请求上下文。
- `i18n.Localize(ctx, messageID, data)` 适合在 handler 里直接获取本地化结果。

## 配置

```toml
[i18n]
default_language = "zh"
supported_languages = ["zh", "en"]
query_key = "lang"
header_key = "Accept-Language"
```

## 推荐顺序

1. 先注册 `components.LogsComponent()`。
2. 再注册 `components.I18nComponent()`。
3. 在 HTTP 组中加入 `middleware.I18n()`。
4. 业务 handler 使用 `i18n.Localize(...)` 输出消息。

## 验证

- `go test ./i18n`
- `go test ./app/components`
- `go test ./http_server/middleware`
